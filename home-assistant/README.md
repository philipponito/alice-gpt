# Мой GPT — Home Assistant, версия 0.4

Компонент связывает приватный навык с выбранной локальной Яндекс Станцией. Готовые ответы возвращаются через фиксированную команду «Скажи навыку Мой GPT готовый ответ». Секрет привязки хранится только в записи интеграции Home Assistant; ключ настройки владельца после привязки не сохраняется.

## Установка и обновление

1. Установить YandexStation из репозитория AlexxIT и войти в аккаунт Яндекса. Не публиковать Home Assistant в интернет.
2. Убедиться, что у нужного `media_player` есть локальный атрибут `alice_state`.
3. Загрузить установщик рядом с `configuration.yaml`. Для существующей установки выполнить `python3 /homeassistant/install-alice-gpt-voice.py --update`, указав фактический путь файла.
4. Полностью перезапустить Home Assistant. Привязка в `.storage` сохраняется, повторно добавлять интеграцию не нужно.
5. Для первой установки добавить интеграцию «Мой GPT — ответы на колонке», выбрать колонку, получить код командой навыку «подключи колонку» и ввести код и ключ владельца в форму.

Установщик проверяет контрольные суммы и сохраняет прежний компонент в `alice_gpt_voice_backups` за пределами `custom_components`. При ошибке замены восстанавливает прежнюю папку. Старые `.alice-gpt-backup-<32 hex>` с domain `alice_gpt_voice` переносятся туда целиком: скрытые папки внутри `custom_components` тоже сканируются загрузчиком Home Assistant и могли подменить актуальную версию. `configuration.yaml` и `.storage` не изменяются.

## Ответы и ожидание

- Пустое приветствие воспроизводит загруженный владельцем короткий звук, в чате отображается «Слушаю».
- Для долгих запросов начальный ответ — короткий сигнал. Уже начатый запрос модели продолжает выполняться в фоне, повторный запрос для продолжения не нужен.
- Быстрый обычный ответ возвращается напрямую. Если обычная генерация не завершилась за бюджет переднего ответа, обработчик сохраняет результат зашифрованным и ставит его в очередь озвучки. Долгая маршрутизация к Google/поиску передаёт доставку соответствующему job, без второго объявления.
- Тайм-аут Яндекс Диалогов остаётся 4,5 секунды. Рабочий запрос модели получает до 90 секунд, Google — до 70 секунд, поиск — до 70 секунд. Vercel Fluid Compute для `/api/alice` разрешает до 240 секунд на обработчик вместе с фоновыми задачами. Это конечные бюджеты; сбои провайдера, сети и хранилища всё ещё возможны.
- При выключенном компьютере автоматической озвучки нет; можно получить последний результат командой «готово». Базовые GPT и Google работают на Vercel без Home Assistant.
- Результат истекает через пять минут, автоматическая доставка и одноразовый ответ — через 90 секунд. Текст Google и готовые ответы зашифрованы. Доставка забирается до команды колонке и не повторяется при неясном исходе; это защита от повторов, а не гарантия доставки.
- Устройство опрашивает сервер каждые пять секунд. Во время разговора передаётся только присутствие; ответы и команды принимаются в IDLE. Опрос создаёт регулярные обращения Vercel/Redis.
- Текст модели никогда не исполняется как команда. Команда возврата фиксирована и не содержит длинного кода. Чужой пользователь и один лишь application_id не могут получить личный ответ.
- Привязка автоматически продлевается работающим мостом до 30 дней, не чаще раза в сутки. После примерно 30 дней бездействия потребуется повторная привязка. Новая привязка отзывает старый токен.

## Свет

В этой установке разрешены только:

| Имя в навыке | Объект Home Assistant |
| --- | --- |
| Свет в комнате, свет | `light.komnata_na_tretem_rozetka` |
| Кухонная лампа, свет на кухне | `light.kukhnia_lampa_kukhonnaia` |

Исходные подключения к «Дому с Алисой» сохраняются. Компьютер и плитка не входят в список действий GPT. Прямые команды света проходят без модели. Неоднозначное «включи/выключи лампу» сохраняет действие зашифрованным на 90 секунд; место уточняется только следующей репликой того же пользователя в той же сессии.

Команды выдаются исполнителю один раз, истекают через 45 секунд и не накапливаются на выключенном компьютере. Компонент вызывает только `light.turn_on/off` для двух заданных объектов. Начальное подтверждение и успешный результат молчаливы; озвучивается только ошибка или невозможность подтвердить состояние. Проверяется состояние, сообщённое интеграцией, а не физический свет. Автоматического повтора после неопределённого результата нет.

## Экспериментальное удержание навыка

После установки 0.4 сказать навыку «включи постоянный режим». По умолчанию он выключен. «Статус постоянного режима» сообщает доступность моста и возраст последнего действительно пришедшего в навык служебного обращения.

После 90 секунд без взаимодействия сервер может разрешить одну фиксированную команду «Скажи навыку Мой GPT поддерживай связь». Ответ — 100 мс тишины с `end_session=false`. Клиент дополнительно требует IDLE не менее 20 секунд, не воспроизводящую музыку колонку и повторно проверяет состояние перед отправкой. Служебная команда не вызывает модель, Google и действия света. Пока компьютер выключен, механизм не работает.

Это попытка поддерживать или заново открывать навык, а не настройка тайм-аута Яндекса. `alice_state` не показывает, какой навык открыт. Проверочный запрос сам может продлевать сессию, а активация может создавать новую сессию; точный момент её закрытия так не измеряется. Работу необходимо проверить на реальной колонке после нескольких минут тишины.

Для отключения сказать «выключи постоянный режим». Если команда выхода приходит в наш webhook, режим также отключается в фоне. Яндекс может перехватить системное «Стоп» без обращения к webhook; поэтому для надёжного отключения сначала использовать явную команду выключения режима. При смене сессии долговременная память и авторизация Google не удаляются.

## Поиск

Serper выполняет максимум два поисковых запроса. Агент дополнительно пытается извлечь тексты до двух HTTPS-страниц из результатов через фиксированный endpoint Serper; прямых запросов к произвольным URL с секретами приложения нет. Запрещены IP-адреса, локальные домены, нестандартные порты и credentials в URL. Ответ извлечения ограничен 200 КБ, текст страницы — 9000 символами. Если извлечение недоступно, остаются фрагменты с явным признаком неполноты.

Модель получает московскую дату и границы текущей недели, различает дату статьи, кинотеатральную премьеру, цифровой релиз и наличие HD. Неподтверждённые даты и доступность нельзя выдумывать. Поиск получает только текущий публичный вопрос и отдельный публичный контекст, без Google-документов, писем и долговременных фактов.

## Диагностика и проверки

«Статус дома» проверяет связь без модели. Установленная версия на диске сама по себе не доказывает загрузку нового кода: после обновления нужен полный перезапуск.

`node --test` — синтетические аккаунты и поддельные Redis/OpenAI/Google/Serper: приватность, дедупликация, фоновое ожидание, молчаливый свет, режим удержания и чтение страниц. `python -m unittest discover -s home-assistant -p 'test_*.py'` — разрешённые устройства, проверка состояния, установка, резервные копии и фильтрация удержания во время музыки/прослушивания. Эти проверки не заменяют проверку на реальной Станции.
