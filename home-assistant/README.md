# Экспериментальная озвучка готовых ответов

Этот компонент ещё требует проверки на реальной Станции Лайт. Он получает готовый ответ фонового Google job и вызывает только `media_player.play_media` с типом `text`. Команды создания, переноса или удаления календарных событий никогда не повторяются для получения результата.

## Установка и проверка

1. Установить Home Assistant в домашней сети. Для Windows используется Home Assistant OS в VirtualBox с сетевым мостом. Не открывать Home Assistant в интернет.
2. Установить [Yandex Station](https://github.com/AlexxIT/YandexStation) из официального репозитория автора и авторизоваться по QR-коду владельца колонки. Интеграция сохранит токен Яндекса и создаст служебные сценарии. Вход и предоставление доступа выполняет владелец.
3. Убедиться, что Станция подключена локально: у её `media_player` появился атрибут `alice_state`. На Станции Лайт пользователь проверил: `text` произносит фразу без прослушивания; `dialog` включает прослушивание обычной Алисы и не сохраняет навык. Команда `Запусти навык Мой GPT` с типом `command` возвращает в навык; команда «Статус Google» затем перечисляет подключённые сервисы. Облачный режим обрезает текст и для этого эксперимента не используется.
4. Собрать установщик `python tools/build-voice-installer.py`. Загрузить `public/install-alice-gpt-voice.py` через File editor в папку рядом с `configuration.yaml` и запустить его Python 3 из этой папки. Он устанавливает только `custom_components/alice_gpt_voice`, проверяет контрольные суммы и отказывается перезаписывать существующий компонент. Затем перезапустить Home Assistant. Альтернатива — вручную скопировать папку компонента в `/config/custom_components`.
5. В настройках интеграций добавить «Мой GPT — ответы на колонке». Выбрать именно нужную колонку. Сказать навыку «подключи колонку», ввести код и существующий ключ настройки владельца в форму Home Assistant. Ключ отправляется только серверу этого навыка и не сохраняется компонентом. Для теста привязка действует 30 дней; новая привязка отзывает предыдущую.
6. Задать вопрос Google. Быстрые ответы идут обычным путём через Алису. Для отложенного ответа при работающем мосте навык скажет, что озвучит его автоматически. Компьютер должен оставаться включённым.

## Поведение и ограничения

- Опрос выполняется каждые 10 секунд, только когда выбранная колонка доступна локально. Это добавляет до 10 секунд к доставке готового ответа и создаёт регулярные запросы Vercel/Redis. Перед постоянной эксплуатацией проверить фактическое использование тарифов.
- Токен моста позволяет читать только отложенные ответы привязанного пользователя. Не даёт создавать Google jobs или менять календарь. Токен хранится в конфигурации Home Assistant; не включать её в публичный Git и не публиковать диагностические архивы с секретами.
- Содержимое Google хранится зашифрованным в Redis; результат истекает через пять минут, автоматическая доставка — через 90 секунд. Возвращается только отложенный ответ, быстрые ответы дополнительно не озвучиваются.
- Сервер одноразово забирает результат до отправки клиенту. При обрыве соединения или неясном исходе озвучка не повторяется: ручное «готово» позволяет получить тот же ответ. Это защита от повторов, а не гарантия доставки.
- Ссылки удаляются из текста перед отправкой на колонку, поскольку Yandex Station может трактовать их как поток медиа. Используется только речь, не тип `command`.
- Для автоматического возврата используется `text`, затем наблюдение перехода `SPEAKING → IDLE`, затем фиксированная команда запуска «Мой GPT». При отключении колонки, вмешательстве пользователя или отсутствии подтверждённого окончания речи за 150 секунд возврат не выполняется. Начинается новая сессия навыка; это не сохранение старой сессии. Полная автоматическая цепочка ещё требует проверки на реальном устройстве.
- Google OAuth и подключение колонки независимы. Остановка Home Assistant не отключает Google; остаётся обычное получение ответа через навык.

## Проверки

`node --test` — синтетические аккаунты, поддельные Google/OpenAI/Redis. `python home-assistant/test_delivery.py` — проверка обычного текста и защиты от интерпретации ссылок как медиа. Эти проверки не заменяют тест на колонке и загрузку компонента настоящим Home Assistant.
