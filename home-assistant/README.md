# Экспериментальная озвучка готовых ответов

Компонент 0.2 получает одноразовый номер готового фонового ответа и передаёт его навыку командой «Скажи навыку Мой GPT ответ колонки …». Навык возвращает уже подготовленный текст с `end_session=false`. Команды создания, переноса или удаления календарных событий никогда не повторяются для получения результата. Полная автоматическая цепочка версии 0.2 ещё требует проверки на реальной Станции Лайт.

## Установка и проверка

1. Установить Home Assistant в домашней сети. Для Windows используется Home Assistant OS в VirtualBox с сетевым мостом. Не открывать Home Assistant в интернет.
2. Установить [Yandex Station](https://github.com/AlexxIT/YandexStation) из официального репозитория автора и авторизоваться по QR-коду владельца колонки. Интеграция сохранит токен Яндекса и создаст служебные сценарии. Вход и предоставление доступа выполняет владелец.
3. Убедиться, что Станция подключена локально: у её `media_player` появился атрибут `alice_state`. На Станции Лайт пользователь проверил: команда «Скажи навыку Мой GPT статус Google» с типом `command` возвращает ответ навыка и позволяет сразу задать следующий вопрос без обращения «Алиса». Облачный режим для доставки не используется.
4. Собрать установщик `python tools/build-voice-installer.py`. Загрузить `public/install-alice-gpt-voice.py` через File editor в папку рядом с `configuration.yaml` и запустить его Python 3 из этой папки. Он устанавливает только `custom_components/alice_gpt_voice`, проверяет контрольные суммы и отказывается перезаписывать существующий компонент. Затем перезапустить Home Assistant. Альтернатива — вручную скопировать папку компонента в `/config/custom_components`.
5. В настройках интеграций добавить «Мой GPT — ответы на колонке». Выбрать именно нужную колонку. Сказать навыку «подключи колонку», ввести код и существующий ключ настройки владельца в форму Home Assistant. Ключ отправляется только серверу этого навыка и не сохраняется компонентом. Привязка автоматически продлевается активным мостом до 30 дней, не чаще раза в сутки. После примерно 30 дней бездействия потребуется подключение заново; новая привязка отзывает предыдущую. Продление выполняется сервером и действует также для уже установленного компонента.
6. Задать вопрос Google. Быстрые ответы идут обычным путём через Алису. Для отложенного ответа при работающем мосте навык скажет, что озвучит его автоматически. Компьютер должен оставаться включённым.

Для обновления установленного компонента загрузить новый установщик и выполнить `python3 /homeassistant/install-alice-gpt-voice.py --update` (путь зависит от места загрузки). Он сохраняет прежнюю папку компонента как `.alice-gpt-backup-…` рядом с новой. При ошибке замены восстанавливает прежнюю папку. `configuration.yaml` и `.storage` не меняются: привязка сохраняется. После обновления перезапустить Home Assistant; повторно добавлять интеграцию не требуется.

## Поведение и ограничения

- Опрос выполняется каждые 10 секунд, только когда выбранная колонка доступна локально. Это добавляет до 10 секунд к доставке готового ответа и создаёт регулярные запросы Vercel/Redis. Перед постоянной эксплуатацией проверить фактическое использование тарифов.
- Сервер считает мост доступным в течение 180 секунд после последнего опроса: установленный компонент не опрашивает сервер во время прослушивания и собственной озвучки. После выключения компьютера переход к ручному получению ответа может занять до трёх минут. Команда возврата «Запусти навык Мой GPT», попавшая в уже открытый навык, обрабатывается без модели: короткий звук и продолжение прослушивания.
- Токен моста позволяет читать только отложенные ответы привязанного пользователя. Не даёт создавать Google jobs или менять календарь. Токен хранится в конфигурации Home Assistant; не включать её в публичный Git и не публиковать диагностические архивы с секретами.
- Содержимое Google хранится зашифрованным в Redis; результат истекает через пять минут, автоматическая доставка — через 90 секунд. Возвращается только отложенный ответ, быстрые ответы дополнительно не озвучиваются.
- Сервер одноразово забирает результат до отправки клиенту. При обрыве соединения или неясном исходе озвучка не повторяется: ручное «готово» позволяет получить тот же ответ. Это защита от повторов, а не гарантия доставки.
- Текст модели никогда не используется как команда колонки. Фиксированная команда содержит только случайный номер ответа из 64 шестнадцатеричных символов. Ответ хранится зашифрованным ещё 90 секунд, привязан к пользователю навыка и забирается одноразово; номер без соответствующего Яндекс-пользователя не даёт доступа к тексту.
- Версия 0.2 возвращает ответ через webhook самого навыка и продолжает прослушивание. Прежняя версия компонента продолжает получать текст старым способом до обновления.
- Google OAuth и подключение колонки независимы. Остановка Home Assistant не отключает Google; остаётся обычное получение ответа через навык.

## Проверки

`node --test` — синтетические аккаунты, поддельные Google/OpenAI/Redis, одноразовая доставка и проверка владельца. `python -m unittest discover -s home-assistant -p 'test_*.py'` — проверка допустимых команд, установки и сохранения привязки при обновлении. Эти проверки не заменяют тест на колонке.
